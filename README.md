# Hello World Projekt

## Beschreibung
Dieses Projekt ist unser erstes gemeinsames „Hello World“-Programm.  
Ziel war es, den grundlegenden Git-Workflow kennenzulernen und praktisch anzuwenden.

## Ziele
- Git Repository erstellen
- Änderungen committen
- Mit Branches arbeiten
- Pull Requests erstellen und mergen

## Verwendeter Workflow
1. Repository erstellt
2. Lokales Klonen des Repos
3. Erstellen eines neuen Branches (`feature/hello-world`)
4. Schreiben des Hello-World-Codes
5. Commit der Änderungen
6. Push zum Remote-Repository
7. Pull Request erstellt
8. Code überprüft und gemerged

Änderung auf lokaler Kopie
